# Enzova — brand assets

First-draft logo, based on `Brand Starter — Identidade Inicial da Marca`.
Hand-built as flat SVG geometry (no external design tool), so these are a
starting point — not final production files. A vector illustrator pass
(fonts converted to outlines, refined bar proportions) is recommended
before print use (cards, signage).

## Files

- `icon.svg` — standalone mark (favicon, GitHub/LinkedIn avatar, app icon).
- `logo-stacked.svg` — primary lockup (icon + ENZOVA / TECH), for light backgrounds.
- `logo-horizontal.svg` — same lockup, horizontal, for light backgrounds/headers.
- `logo-horizontal-light.svg` — reversed (white wordmark, no icon tile) for dark backgrounds.

## Concept

Three geometric bars, increasing in length, tilted slightly — reads as an
abstract "E" while also suggesting forward motion (idea → development →
product), per Brand Starter §23–24. Deliberately not a literal
computer/brain/circuit/cloud icon.

## Typography

Wordmark: **Manrope** (Bold/ExtraBold). UI/body: **Inter**. Neither font
is bundled here — the SVGs reference `Manrope, Arial, sans-serif` and fall
back to the system sans if Manrope isn't installed/loaded.
